# CareerOS
> 个人能力画像与动态职业发展路径推荐系统（机器学习项目实训）

本项目旨在解决传统职业测评工具“重兴趣轻能力”、“缺乏市场数据支撑”、“推荐结果静态固定”等痛点。系统将基于个人特征、能力发展轨迹与就业市场数据，输出 Top-5 职业方向、能力差距分析与可交互的发展树，为用户提供持续更新的职业发展建议。

## 团队分工（5人）

- **吕宛泽（全流程质控兜底 / 前端）**：M1 问题定义与口径、M8 工程底座、M9 决策与设计文档。全权负责 **Flutter 客户端**开发（填报表单、推荐卡片、发展树可视化和前后端联调），以及全流程代码质检。
- **高帅龙（数据知识库）**：M2 数据管道；负责 O*NET / ESCO 职业-技能知识库构建、技能映射规则制定、静态数据冻结与指纹。
- **赵帝臣（模型算法）**：M3 训练与评估、M4 模型包；负责预训练嵌入匹配算法、三档能力差距判定、模型包封装与指标输出。
- **代旭（后端服务 / 动态数据清洗）**：M5 后端服务；负责 FastAPI 接口开发、422 校验；并负责招聘市场数据（如 Adzuna）的爬取、清洗，为模型和服务提供动态市场需求数据。
- **薛宏博（监控 /  报告）**：M7 监控与回流；负责技能分布漂移检查（PSI）、Pytest 全链路测试用例；统筹最终分析报告排版与统稿。

## 目录结构与边界
本仓库严格遵循模块解耦原则，严禁跨层越界引用：
```text
careeros/
├── configs/               # 全局配置（统一口径、特征目录、超参数）
├── data/                  # 数据目录（raw 不入库，processed 走指纹）
│   ├── FROZEN.json        # 冻结数据集指纹（高帅龙主责）
│   └── manifest.json      # 数据集元信息
├── docs/                  # 项目文档
│   ├── problem.md         # 问题定义与目标
│   ├── spec.md            # 业务口径规格
│   ├── decisions.md       # 核心决策记录（ADR）
│   ├── data_card.md       # 数据卡
│   └── model_card.md      # 模型卡
├── packages/              # Python 核心包
│   ├── core/              # 领域模型与数据契约（Pydantic，吕宛泽主责）
│   ├── training/          # 训练、评估与模型导出（赵帝臣主责，禁止被 service import）
│   └── service/           # FastAPI 后端服务与招聘数据清洗脚本（代旭主责）
├── apps/
│   └── admin-web/         # (废弃) 前端统一移至 Flutter 独立仓库，此目录保留空壳
├── scripts/               # 各模块独立执行脚本
│   ├── build_dataset.py   # 知识库构建入口（高帅龙）
│   ├── train.py           # 训练入口（赵帝臣）
│   └── check_drift.py     # 漂移检查入口（薛宏博）
└── tests/                 # Pytest 测试用例（薛宏博主责）

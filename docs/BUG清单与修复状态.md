   用例总数 87 → 89。复测 89 条 **全部通过（89 passed / 0 failed）**，3 条历史失败全部转绿，无回归。

> 合并验证已完成：映射层在 main 上按同命令复测通过，无回归。
> 复测时若映射层出现 4 条 CRLF/sha256 失败，是 Windows `core.autocrlf=true` 在 checkout 时把
> CSV 的 LF 转成 CRLF 所致，非数据缺陷——git blob 与 manifest 登记的 sha256 一致（均 `498a4d...`）。
> 用 `git -c core.autocrlf=false checkout -- <映射文件>` 重新检出后即全绿。
> 另：新后端 `packages.service.main` 依赖 pandas，测试包便携 Python 已补装 pandas 2.3.3 /
> numpy 2.5.5，否则会静默降级到 stub 导致"假通过"。

89 条用例现已全部在真实后端上通过：数据版本层（21）+ 契约层（23）+ 映射层（13）直接读真实交付物，
接口/异常（15，含发展树结构 2 条）+ 算法/推荐（15）+ 链路（2）已接真实后端与正式算法，结论均为真实验收。

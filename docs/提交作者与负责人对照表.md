## 一、这是什么、怎么验证

`.mailmap` 放在仓库根目录，作用是**只改 `git log` 的显示署名，不改历史提交对象**。
同一人的多个邮箱/名字会被显示成一个规范姓名。

```bash
# 看归一后的作者名
git log --format='%aN' | sort -u

# 看归一前后对照
git check-mailmap 'lvwanze <yizhilaobu@qq.com>'
```

答辩时老师问「谁做了什么」，按第三节的五项负责人分工回答；
老师追问「为什么 git log 名字和 README 对不上」，就说「加了 `.mailmap` 统一署名，配了这张对照表」。

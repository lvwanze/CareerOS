# CareerOS 项目问题定义与目标

## 1. 项目基本信息

- 项目名称：CareerOS
- 项目中文名称：个人能力画像与动态职业发展路径推荐系统
- 研究选题：《融合就业市场需求与个人能力画像的职业适配分析及发展路径推荐研究》
- 项目阶段：机器学习课程实训第一阶段 MVP
- 项目类型：个人能力画像、职业推荐与发展路径分析系统

## 2. 项目背景与问题定义

传统职业测评工具通常根据用户兴趣、性格或问卷结果进行职业推荐，但存在以下不足：

1. 过度依赖兴趣和性格标签，缺少对个人实际能力的分析。
2. 推荐职业后，缺少具体的能力差距分析和发展建议。
3. 职业推荐与实际就业市场需求之间缺少有效联系。
4. 用户能力和职业目标发生变化后，系统难以动态调整推荐。
5. 容易形成固定职业标签，限制用户探索其他职业方向。

CareerOS 希望结合个人特征、能力基础、职业技能要求与就业市场信息，帮助用户理解自身能力与职业需求之间的关系，并提供可调整的发展建议。

## 3. 核心目标

系统围绕五个问题展开：

1. 我是谁？——理解个人兴趣、学习阶段、能力基础和现实条件。
2. 我能走向哪里？——探索多个可能的职业发展方向。
3. 这些方向需要什么？——识别职业所需的核心技能与能力。
4. 未来可能发生什么？——了解就业市场需求与技能变化。
5. 我下一步可以做什么？——根据能力差距规划发展路径。

核心目标是建立个人能力、职业要求和就业市场需求之间的联系，而不是单纯输出职业测评标签。

## 4. 产品功能规划

### 4.1 个人职业画像

长期规划包含六个维度：

- 偏好：兴趣领域、工作方式、工作环境。
- 学习阶段：学历、专业、当前学习阶段。
- 核心能力：专业技能、通用能力及能力证据。
- 社会资源：导师支持、实践机会、合作资源。
- 现实约束：可投入时间、预算、地域偏好等。
- 职业想法：目标职业、职业兴趣和人生目标。

第一阶段优先实现学习阶段、偏好、核心技能、部分现实约束和职业目标。

### 4.2 多职业方向推荐

结合用户画像与职业技能要求，计算职业匹配程度，输出 Top-5 职业方向。

推荐结果应包括：

- 职业名称和唯一标识。
- 匹配分数。
- 推荐依据。
- 已具备技能。
- 待加强技能。
- 待验证能力。

匹配分数仅代表模型内部的相对适配指标，不代表用户进入某职业的统计概率。

### 4.3 职业市场分析

通过招聘岗位数据分析：

- 岗位需求数量。
- 核心技能需求。
- 薪酬分布。
- 学历和工作经验要求。
- 不同时间段的技能需求变化。

第一阶段优先完成可用招聘样本的基础统计，不强制实现未来趋势预测。

### 4.4 个人发展路径

根据目标职业要求与用户当前能力，生成技能提升建议。

第一阶段采用规则化发展路径，展示技能节点、当前状态和建议学习方向。

长期规划支持技能共享、技能依赖关系和多职业发展网络。

### 4.5 动态成长反馈

长期规划支持根据学习成果、项目经历、能力证明和用户反馈更新画像及职业推荐。

该功能暂不作为第一阶段的完整交付要求。

## 5. 第一阶段 MVP 范围

第一阶段开发周期有限，优先完成完整可运行的核心业务链路。

必须完成：

1. 用户基础画像填报。
2. 用户技能信息录入。
3. 职业与技能知识库。
4. 基础职业匹配算法。
5. Top-5 职业推荐。
6. 推荐依据与技能差距分析。
7. 基础发展路径生成。
8. Flutter 前端与 FastAPI 后端联调。
9. 核心业务流程测试。

暂不要求完整实现：

- 复杂深度学习推荐模型。
- Sentence-BERT 嵌入模型。
- 协同过滤。
- 技能需求预测模型。
- 完整社会资源画像。
- 多职业共享技能网络的复杂交互。
- 长期成长记录与增量更新。
- PSI 漂移监控。

## 6. 第一阶段技术路线

数据层：
- O*NET 职业技能数据。
- 可获取的招聘岗位样本。
- 用户主动填写的画像数据。

算法层：
- 技能向量化。
- 余弦相似度。
- 加权职业排序。
- 技能等级差值。
- 规则化发展路径。

后端：
- Python。
- FastAPI。
- Pydantic。
- Pandas / NumPy。

前端：
- Flutter。

测试：
- Pytest。

## 7. 核心业务流程

用户填写个人画像
→ 后端接收并校验数据
→ 构建个人技能画像
→ 读取职业技能知识库
→ 调用职业匹配算法
→ 输出 Top-5 职业
→ 分析技能差距
→ 组织发展路径
→ 返回前端展示。

## 8. 项目验收标准

- 用户能够填写个人画像。
- 系统能够正确处理用户技能数据。
- 系统能够生成 Top-5 职业推荐。
- 推荐结果具有可解释依据。
- 系统能够识别已具备、待加强和待验证的能力。
- 系统能够生成基础发展路径。
- Flutter 能够通过 API 获取结果。
- 核心业务流程通过基础测试。
- 项目具备可复现的运行说明和完整文档。

## 9. 后续发展方向

第二阶段以个人毕业设计为目标，重点研究：

1. 多维个人特征融合与职业适配模型。
2. 职业技能知识库和语义匹配。
3. 国内招聘市场技能需求分析。
4. 技能需求变化预测。
5. 基于技能依赖图的动态发展路径规划。
6. 用户成长反馈与职业推荐动态更新。

第一阶段的架构设计应尽量为上述方向保留扩展空间。
